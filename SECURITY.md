# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

- **GitHub:** [open a private security advisory](https://github.com/hazyrealm/emix/security/advisories/new)

Include what you found, how to reproduce it, and the impact you expect. We will
acknowledge your report, keep you informed while we work on a fix, and credit
you in the release notes if you would like.

## Scope

- The Emix service at `getemix.com`, `app.getemix.com` and its subdomains
- The Emix desktop app for Windows
- The source code in this repository

Please do not run denial-of-service tests, spam other users, or access accounts
or data that are not yours.

## Supported versions

Only the latest release receives security fixes. The Emix service always runs
the latest version, and the desktop app updates itself automatically.
